# Owned blank fixture

owned-blank.hwpx SHA256 c8b7a78482b6c46fc506832b85b52f33434a6c90b048babc0cdaa471f653d774 is a blank HWPX generated by an earlier version of this project. It contains no user text and provides a real HWPX header and style table. Tests add their own Unicode text in memory only.

An earlier createEmpty() fixture had no DocInfo character shapes, so upstream's document agent correctly refused to apply charShapeId 0; that fixture was replaced by this one rather than weakening the adapter.
