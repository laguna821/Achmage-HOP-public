# Codex app-server schemas

The `*Params.json` and `*Response.json` schemas in this directory were generated by the OpenAI Codex CLI 0.128.0
app server, including the descriptions it carries. OpenAI Codex is licensed under the Apache License 2.0, copyright
OpenAI; the license text is in [licenses/Apache-2.0.txt](../../../../../licenses/Apache-2.0.txt). They are used only
to validate this crate's requests in tests.

`ObservedModelCatalog.json` and `ObservedDesktopModelCatalog.json` are model lists as the app server returned them,
kept as test input for the model picker.
